💡 A API não é exposta externamente — o Nginx faz proxy de /api/* para o container api:3001 internamente.

⚡ Startup Automático

No primeiro boot (e em toda reinicialização), o container da API executa automaticamente:

# entrypoint.sh — executado a cada startup do container api prisma migrate deploy # aplica migrações pendentes tsx prisma/seed.ts # cria admin (idempotente — seguro repetir) node dist/server.js # inicia o servidor Fastify

O seed usa upsert — se o usuário admin já existir com senha alterada, não sobrescreve.

🚀 Deploy no Portainer
  1. 1
    Fazer o build das imagens
    No servidor onde está o código-fonte, execute:
    docker compose -f docker-compose.portainer-mvp.yml build
  2. 2
    Abrir o Portainer
    Acesse a interface do Portainer no servidor do cliente: https://<IP>:9443
  3. 3
    Criar um novo Stack
    Navegue até Stacks → Add Stack → Web Editor
    Cole o conteúdo do arquivo docker-compose.portainer-mvp.yml
  4. 4
    Fazer o Deploy
    Clique em Deploy the stack e aguarde os 3 containers subirem com status ✓ running
  5. 5
    Primeiro acesso
    Acesse http://<IP-DO-SERVIDOR> e faça login com as credenciais de administrador acima.
    Troque a senha imediatamente!
